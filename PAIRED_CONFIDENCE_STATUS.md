# Paired Confidence Pilot v1

7 October 2026. Status: design frozen; dataset construction and Phase A engineering checks in progress.

The target is expressed certainty in content-preserving confident/hedged pairs.
Correctness is balanced and assessed separately. No confidence loss has been
validated. Model weights remain frozen.

Read [the preregistration](PAIRED_CONFIDENCE_PREREGISTRATION_V1.md) for the design
and [the results](PAIRED_CONFIDENCE_RESULTS_V1.md) for completed evidence.
