## Source and design

- Source: [UltraChat 200k](https://huggingface.co/datasets/HuggingFaceH4/ultrachat_200k), `train_sft`, MIT license. These are synthetic ChatGPT conversations, not real-user transcripts or verified factual gold.
- Recorded dataset revision: `8049631c405ae6576f93f445c6b8166f76f5505a`. Raw dataset-server pages, complete source rows, IDs, timestamps, and text hashes are cached.
- From 4,000 inspected rows, 50 first-turn information-seeking question/answer examples were purposively selected. Original answers contain 40–180 words, 6,128 words in total. This is not a random sample.
- Each record contains the unchanged question and original answer, plus a confident and a hesitant rewrite. Neither source answer is truncated or silently corrected.
- Writer: `claude-haiku-5-5`, called in batches of five through the existing Harvard Claude login, with tools and persistent sessions disabled. A small auxiliary Haiku 4.5 usage entry is retained separately in provider metadata; it is not the rewrite writer.
- The prompt changes the speaker's commitment while retaining entities, quantities, negation, conditions, scope, and substantive source qualifications. It prohibits invented verification and detachable confidence boilerplate.
- Sixteen source records received bounded content-preservation repairs; two of these needed a further correction. All attempts remain cached. Repairs do not constitute independent human certification.
